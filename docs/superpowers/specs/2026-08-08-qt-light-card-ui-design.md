# Qt 界面重设计 — 方案 B(浅色现代卡片风)

日期:2026-08-08
状态:设计已确认,待实现

## 1. 背景与现状

当前主窗口为 1024×600,左侧 200px 黑色 `QListWidget` 导航 + 右侧 `QStackedWidget`,共 7 个功能模块。`style/mainstyle.qss` 基本为空(仅一行深色背景),音乐/视频页各自携带深色样式与深色按钮图。

目标:在不改动任何功能逻辑的前提下,把整个界面重设计为**浅色现代卡片风**:顶部标签导航、白色圆角卡片、统一的浅色配色与图标。

## 2. 目标与非目标

目标:

- 主框架改为顶部标签导航,内容区卡片化。
- 7 个页面全部统一为浅色卡片风格。
- 音乐/视频页按钮图替换为浅色图标,整体无深色残留。
- 保留现有全部功能:轮播图、OpenCV、摄像头人脸、板级设备、音乐、视频、MQTT。
- 现有自动化测试 12/12 继续通过(导航控件保留兼容 API)。

非目标:

- 不改任何业务逻辑、设备路径、OpenCV/MQTT 代码。
- 不新增功能模块。
- 不做深色主题(未来可扩展)。

## 3. 整体框架

```
┌────────────────────────────────────────────────────────┐
│ 标题       标签1 标签2 标签3 标签4 标签5 标签6 标签7  时间 │  ← 64px 白色标签栏
├────────────────────────────────────────────────────────┤
│                                                        │
│             白色圆角卡片区(10px 圆角,1px 浅灰描边)        │
│                                                        │
└────────────────────────────────────────────────────────┘
```

- 窗口尺寸保持 1024×600。
- 顶部标签栏:高 64px,白底;左侧标题“imx6ull 工程”,中间 7 个模块标签,右侧当前时间(格式 `HH:mm`,每秒刷新)。
- 选中标签:主色蓝 `#2F7CF6` 圆角药丸背景、白字;未选中:深灰文字 `#374151`。
- 内容区背景 `#F4F6F8`,所有页面内容放入白色卡片。

### 导航实现决策

顶部标签栏采用**横向 `QListWidget`**(`setFlow(QListView::LeftToRight)`,`setWrapping(false)`,固定高 64px)实现,并保留 `objectName = "listWidget"` 与现有 `currentRowChanged → setCurrentIndex` 连接。原因:

- 现有测试(`tests/tst_mainwidget`)通过 `findChild<QListWidget*>("listWidget")`、`count()`、`item(i)->text()`、`setCurrentRow()` 断言,横向模式不改这些 API,测试无需修改。
- 视觉上通过样式表实现药丸选中态,与 QTabBar 效果一致,但改动面更小。

若实现时横向 `QListWidget` 样式无法达到预期,允许改用 `QTabBar`,此时必须同步更新 `tst_mainwidget.cpp` 的断言(此项为唯一允许的例外,需在提交说明中注明)。

## 4. 配色

| 用途 | 色值 |
|---|---|
| 页面背景 | `#F4F6F8` |
| 卡片背景 | `#FFFFFF` |
| 卡片描边 | `#E5E7EB` |
| 主色(选中、主按钮、链接) | `#2F7CF6` |
| 成功/在线 | `#22C55E` |
| 警示 | `#F59E0B` |
| 错误 | `#EF4444` |
| 主文字 | `#1F2937` |
| 次要文字 | `#6B7280` |
| 图标默认色 | `#374151`(深灰) |

按钮规则:

- 主操作按钮:主色蓝实底、白字、圆角 8px、高 ≥ 44px。
- 次要按钮:白底、1px 描边 `#D1D5DB`、深灰文字。
- 危险/断开操作:红底或白底红字。

## 5. 字体与触控

- 标题 20px 粗体;正文 14~16px;大数字 28~36px(传感器、MQTT 状态)。
- 字体使用系统默认中文渲染(Windows 微软雅黑;板端思源黑体/文泉驿,若无则回退默认)。
- 所有可点击控件高 ≥ 44px,点击区域不小于 44×44。
- 不使用阴影、半透明层叠等重渲染效果,保证 eglfs 性能。

## 6. 各页面布局

### 6.1 轮播图

- 居中大图卡片(圆角 10px,图片按比例缩放显示)。
- 左右各一个圆形浅色箭头按钮(直径 44px,白底、蓝色图标)。
- 底部圆点指示器(当前页蓝点,其余灰点)。
- 下方一行小缩略图卡片,点击可切换。

### 6.2 OpenCV 测试

- 左卡片:原图/处理结果预览(浅灰棋盘格占位背景)。
- 右卡片:功能按钮网格(预处理/滤波/边缘检测/噪声/分割/变换/特征),按现有功能分组。

### 6.3 摄像头人脸识别

- 左卡片:实时画面(浅灰背景,黑色边框内嵌)。
- 右卡片:设备下拉框 + 开始/停止、拍照、人脸检测按钮;拍照结果以弹窗或下方缩略卡展示。

### 6.4 imx6ull 板级设备

- 上排卡片:LED、蜂鸣器状态卡(开启绿色、关闭灰色)。
- 中排卡片:AP3216C(ALS/PS/IR 大数字)、ICM20608(六轴 + 温度数值)。
- 右侧卡片:实时曲线(浅色背景,蓝色曲线、浅灰网格线)。

### 6.5 音频播放器

- 播放器卡片:封面区 + 标题 + 进度条 + 时间 + 控制按钮(新浅色图标)。
- 左侧歌曲列表卡片;右侧歌词卡片(若有 lrc)。

### 6.6 视频播放器

- 大画面卡片 + 底部浅色控制条(播放/上一集/下一集/音量/全屏)。
- 右侧播放列表卡片。

### 6.7 MQTT_CLIENT

- 连接配置卡片:服务器、端口、客户端 ID、连接/断开按钮;连接成功显示绿色“已连接”徽标。
- 发布卡片:主题 + 消息 + 发布按钮。
- 消息列表卡片:订阅消息滚动列表(系统时间前缀,订阅主题高亮)。

## 7. 图标方案

生成一套浅色 PNG 图标,统一为**扁平线性风格**,默认深灰 `#374151`,主按钮上使用白色版本,尺寸 48×48、透明背景,存放于 `project/images/icons/`。

图标清单:

| 分类 | 图标 |
|---|---|
| 音乐 | 播放、暂停、上一首、下一首、音量+、音量-、收藏、列表 |
| 视频 | 播放、暂停、上一集、下一集、音量+、音量-、全屏、列表 |
| 轮播 | 左箭头、右箭头、圆点(选中/未选中) |
| 设备 | LED 开、LED 关、蜂鸣器开、蜂鸣器关、刷新 |
| 摄像头 | 摄像头、拍照 |
| MQTT | 连接、断开、发送、清空 |
| 通用 | 返回、关闭 |

图标生成要求:

- 透明背景,边缘平滑,无文字。
- 播放/暂停等主控图标同时提供蓝色与白色两版,或由代码按状态叠加底色。
- 生成后加入 `res.qrc`,替换音乐/视频页现有深色按钮图引用。

## 9. 验证计划

1. Windows x86 构建:`x86/build.cmd`,确认无编译错误。
2. 自动化测试:构建 `tests/tests.pro`,`QT_QPA_PLATFORM=offscreen` 下运行 `tst_mainwidget`、`tst_hardware`,12/12 通过。
3. 人工页面检查:逐个切换 7 个标签,确认无深色残留、控件可用、中文正常显示。
4. 板端验证:交叉编译后 eglfs 运行,确认 1024×600 布局、字体、触摸点击正常。

## 10. 风险与注意事项

- 音乐/视频按钮图全部替换后,若个别图标风格不统一,需在实现时迭代素材。
- OpenCV 页面控件较多,卡片布局需保证 1024×600 下不溢出;必要时允许卡片内滚动。
- 浅色曲线图需同步调整坐标轴/网格线颜色,保证可见性。
- 顶部标签 7 个 + 标题 + 时间,1024px 宽度下标签需限宽(约 110px/个),文字过长时使用省略号。
